# layout.tsx의 이해

## layout.tsx

- Next.js 14버전의 `_app.tsx`와 `_document.tsx`의 역할을 함
- 공통으로 적용할 내용을 작성하고, 공통으로 적용할 구조를 작성하는 곳
- `/src/app/layout.tsx`를 **글로벌 레이아웃**이라고 함

```tsx
import type { Metadata } from "next";
import { Geist, Geist_Mono } from "next/font/google";
import "./globals.css";

const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
});

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
});

export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="ko">
      <body className={`${geistSans.variable} ${geistMono.variable}`}>
        <div style={{ border: "5px solid skyblue" }}>
          여기는 공통으로 나옵니다
        </div>
        {children}
      </body>
    </html>
  );
}
```

## /src/search/layout.tsx 생성

- 위의 경우는 글로벌 layout이 적용이 되고 난 후
- 해당 폴더의 layout과 같이 적용이 된다
- 특정한 경로의 별도 레이아웃을 만들고 싶다면 `layout.tsx`를 생성하면 된다
- 이때 children은 별도로 작성을 해줘야 한다

```tsx
export default function Layout({ children }: { children: React.ReactNode }) {

      <h1>여기는 검색 레이아웃</h1>
      <div>{children}</div>
    </div>
  );
}
```

# React 19 - Server Component의 이해

- React Server Component를 줄여서 rsc라고 합니다
- rsc의 사전렌더링 자료는 `rscpayload`라고 합니다
- React 18버전에서 추가된 기능
  - 서버용 컴포넌트
  - 클라이언트용 컴포넌트와 구별하자

**※ 서버용 컴포넌트**

```
- 서버에서 딱 한번만 만든다
- 인터렉션(interaction)이 없는 컴포넌트이다
```

## react 컴포넌트 종류

- React `Server` Component

```
- 실행 시 server에서 1번만 실행된다
- rscpayload라는 문자열 데이터를 생성한다
- 미리 html을 작성하여 client에 전달한다
```

- React `Client` Component

```
- 실행 시 server에서 최초 1번 실행된다
- 실행 시 client에서 다시 1번 실행된다 (Hydration 과정)
- client에서 사용할 js가 번들링되어 적용된다
- 실시간으로 html을 생성하여 동적으로 렌더링된다
- 클라이언트 컴포넌트에서 서버 컴포넌트를 import 하지 않도록 노력하자
=> import 하게되면 서버 컴포넌트가 Next에서 클라이언트 컴포넌트로 변경된다
```

## 기준을 세워보자

- Next에서는 무조건 서버용 컴포넌트가 기본입니다
- 만약, **use 훅**을 사용해야 한다면 별도로 `use client`라고 명시해야 한다
- 만약, **이벤트 핸들러**를 사용해야 한다면 별도로 `use client`라고 명시해야 한다
- 웹 브라우저에서만 실행되는 라이브러리라면 `use client`라고 명시해야 한다

## 서버 컴포넌트 살펴보기

- `/src/app/(with-search)/page.tsx`
  - (with-search)는 라우팅과 상관없다

```tsx
// Next App Router에서는 기본이 server 컴포넌트
import styles from "./page.module.css";

export default function Home() {
  console.log("시작페이지");
  // 외부에 노출이 안됩니다
  // 그러나 .env로 관리할 예정입니다
  const supaKey = "123456";
  console.log(supaKey);

  return <div className={styles.page}>인덱스페이지</div>;
}
```

- 클라이언트용 컴포넌트 사용해야 한다면 `use client` 사용

```tsx
"use client";
// Next App Router에서는 기본이 server 컴포넌트
import { useEffect } from "react";
import styles from "./page.module.css";

export default function Home() {
  console.log("시작페이지");
  useEffect(() => {
    console.log("컴포넌트가 웹브라우저에 보이면 실행"); // 마운트
  }, []);

  return <div className={styles.page}>인덱스페이지</div>;
}
```

### 2. 동적 라우팅

- /src/components/searchbar.tsx

```tsx
"use client";
import { useRouter } from "next/navigation";
import { useState } from "react";

const SearchBar = () => {
  const [search, setSearch] = useState("");
  const onChangeSearch = (e: React.ChangeEvent<HTMLInputElement>) => {
    setSearch(e.target.value);
  };

  // 동적 라우팅
  const router = useRouter(); // import 주의
  const handleSearch = () => {
    router.push(`/search?keyword=${search}`);
  };

  return (
    <div>
      <input type="text" value={search} onChange={(e) => onChangeSearch(e)} />
      <button onClick={handleSearch}>검색</button>
    </div>
  );
};
export default SearchBar;
```

## 검색창 css 및 기능정리

- /src/components/searchbar.tsx

```tsx
"use client";
import { useRouter } from "next/navigation";
import { useState } from "react";
import styles from "@/components/searchbar.module.css";

const SearchBar = () => {
  const [search, setSearch] = useState("");
  const onChangeSearch = (e: React.ChangeEvent<HTMLInputElement>) => {
    setSearch(e.target.value);
  };

  // 동적 라우팅
  const router = useRouter(); // import 주의
  const handleSearch = () => {
    if (!search) {
      return;
    }
    router.push(`/search?keyword=${search}`);
    setSearch("");
  };
  const handleKeyDown = (e: React.KeyboardEvent<HTMLInputElement>) => {
    if (e.key === "Enter") {
      handleSearch();
    }
  };

  return (
    <div className={styles.container}>
      <input
        type="text"
        value={search}
        onChange={(e) => onChangeSearch(e)}
        onKeyDown={(e) => handleKeyDown(e)}
      />
      <button onClick={handleSearch}>검색</button>
    </div>
  );
};
export default SearchBar;
```
